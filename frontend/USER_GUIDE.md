# User Guide: Adding Candidates to the ATS

## Overview

This guide explains how recruiters can add new candidates to the Applicant Tracking System (ATS) using the candidate management form.

## Accessing the Candidate Form

1. Navigate to the Recruiter Dashboard
2. Click the **"Add Candidate"** button in the header
3. The candidate form will appear below the header

## Filling Out the Candidate Form

### Required Fields

All fields marked with an asterisk (*) are required:

- **First Name** - Candidate's given name
- **Last Name** - Candidate's family name
- **Email** - Valid email address (format: user@domain.com)
- **Phone** - Phone number (international format accepted, e.g., +1234567890)

### Optional Fields

- **Address** - Physical address of the candidate

### Adding Education

To add educational background:

1. Scroll to the **Education** section
2. Click the **"Add Education"** button
3. Fill in the required fields:
   - **Institution** - Name of the school/university
   - **Degree** - Degree obtained (e.g., Bachelor of Science)
   - **Field of Study** - Major or area of study (optional)
   - **Start Date** - When the education began
   - **End Date** - When the education ended (optional)
4. To add multiple entries, click **"Add Education"** again
5. To remove an entry, click the **"Remove"** button next to it

### Adding Work Experience

To add work experience:

1. Scroll to the **Work Experience** section
2. Click the **"Add Experience"** button
3. Fill in the required fields:
   - **Company** - Name of the employer
   - **Position** - Job title held
   - **Start Date** - When employment began
   - **End Date** - When employment ended (optional)
   - **Description** - Job responsibilities and achievements (optional)
4. To add multiple entries, click **"Add Experience"** again
5. To remove an entry, click the **"Remove"** button next to it

### Uploading a CV

To upload a candidate's CV:

1. Scroll to the **CV Upload** section
2. Click the file input or drag and drop a file
3. **Accepted file types:** PDF and DOCX only
4. **Maximum file size:** 10MB
5. The file name will be displayed once selected

## Submitting the Form

1. Review all entered information for accuracy
2. Click the **"Add Candidate"** button
3. The button will change to **"Adding Candidate..."** while processing
4. Upon successful submission:
   - A success message will appear
   - The form will be reset
   - The form will close automatically
5. If there are errors:
   - Error messages will appear for each invalid field
   - Correct the errors and resubmit

## Form Validation

The form provides real-time validation:

- **Email format:** Must be a valid email address
- **Phone format:** Must be a valid phone number
- **Required fields:** Cannot be empty
- **File type:** Only PDF and DOCX files are accepted
- **File size:** Must be less than 10MB

Error messages appear below each field with validation issues.

## Closing the Form

To close the form without submitting:

1. Click the **"Close Form"** button in the header
2. All entered data will be lost

## Tips for Recruiters

- **Collect complete information:** Gather all candidate details before starting the form
- **Use consistent formatting:** Enter dates in a consistent format (YYYY-MM-DD is recommended)
- **Upload current CVs:** Ensure the CV is the most recent version
- **Verify contact information:** Double-check email and phone numbers for accuracy
- **Add relevant experience:** Include all relevant work history that helps evaluate the candidate

## Troubleshooting

### Form Won't Submit

- Check that all required fields are filled
- Verify email and phone formats are correct
- Ensure no validation errors are displayed

### File Upload Fails

- Verify the file is PDF or DOCX format
- Check that the file size is less than 10MB
- Try selecting the file again

### Success Message Not Appearing

- Check your internet connection
- Verify the backend server is running
- Refresh the page and try again

## Support

For technical issues or questions about the candidate management system, contact your system administrator.
